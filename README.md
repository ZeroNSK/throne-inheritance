# Throne Inheritance

**Прежнее название репозитория:** `3Sem5Lab`.

Модель наследования престола на C++: хранение семейных связей, регистрация рождения и смерти, вычисление порядка наследования обходом дерева.

**Примерный период реализации:** декабрь 2025. Период указан по истории Git и отражает основную работу над проектом.

## Структура

- `include/ThroneInheritance.h` — интерфейс модели.
- `src/ThroneInheritance.cpp` — реализация обхода семейного дерева.
- `src/main.cpp` — пример использования.

## Сборка

Требуется CMake и компилятор C++17.

```bash
cmake -S . -B build
cmake --build build
./build/throne
```
